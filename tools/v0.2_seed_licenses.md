# v0.2 Bulk-Ingest Seed — Per-Tool License Review

**Stage 20.3.** For each tool in [tools/v0.2_seed.json](v0.2_seed.json), this file
records the documentation license and a keep/drop verdict for the v0.2 bulk
crawl. Verdicts are conservative: when in doubt, DROP. Better to ship 35
tools cleanly than 50 with a takedown-risk surface.

## Verdict legend

- **KEEP** — docs are under a permissive license (CC BY, GFDL, MIT, BSD,
  Apache, public domain, or the project's own clearly-redistributable
  license). Excerpting under fair use is unambiguous.
- **DROP** — docs are © a commercial vendor whose terms forbid or restrict
  redistribution. Excerpting is risky; defer to a post-launch licensing
  conversation.
- **REVIEW** — license is unclear from a quick read; needs a one-line
  follow-up before re-promoting to KEEP. Treated as DROP for the v0.2 crawl.

## Process for re-promoting REVIEW tools

For each REVIEW tool, the unblock task is a one-line confirmation — either
"docs are CC-licensed, KEEP" or "docs ToS forbids redistribution, DROP."
This work is a v0.2.x follow-up, not a v0.2 blocker. Track in a future
`tools/v0.2_seed_licenses_review.md` if needed.
